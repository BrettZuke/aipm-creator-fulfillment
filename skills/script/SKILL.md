# /script — Video Script Writer

Writes complete short-form video scripts optimized for TikTok and Instagram performance.

## Workflow

1. Ask: topic, key points to hit, target audience, video length (15s / 30s / 60s / 90s), tone (educational / entertaining / story-based / controversial), any CTA goal
2. Write the full script with timestamp markers
3. Offer 3 alternative hooks
4. Note any delivery tips (pause here, emphasize this word, etc.)

## Script Structure

**Hook (0–3 seconds)** — pattern interrupt, bold claim, or question that creates a reason to keep watching
**Setup (3–15 seconds)** — establish context, why this matters to them
**Body (15–45 seconds)** — deliver the value. One idea per breath. Short sentences.
**CTA (last 3–5 seconds)** — one action: follow, comment, click link in bio, save this

## Hook Formulas That Work

- "Nobody talks about [unexpected thing]..."
- "Stop doing X. Do this instead."
- "I made [specific result] in [time period] without [expected thing]"
- "[Number] things [audience] gets wrong about [topic]"
- "The [shocking truth / dirty secret / real reason] about [topic]"

## Script Rules

- Write how people talk, not how people write
- No sentences over 10 words
- One idea per sentence
- Read it out loud — if it sounds weird, rewrite it
- The hook is 80% of the result — spend most energy there

## Output

Full script with timestamps + 3 alternative hooks + delivery notes
