# Avoid AI Writing

A two-pass process for removing the writing tells that make text sound AI-generated.

## Pass 1: Detect

Read the draft once. Mark every instance of:

**Banned words/phrases** — see the 43-entry replacement table below.

**Structural tells:**
- Rule-of-three padding (three adjectives or clauses stacked for rhythm: "faster, smarter, and more efficient")
- "X, not Y" / "not just X, but Y" antithesis constructions
- Hedging ("it's worth noting", "arguably", "may potentially")
- Setup-payoff clichés ("here's the thing", "but here's the kicker")
- Extended metaphors used as the spine of a paragraph, not just one line of color
- Uniform sentence rhythm — every sentence the same length is itself a tell
- Throat-clearing openers ("In this post, I'll cover...")
- Exclamation points doing the work a real point should do

## Pass 2: Rewrite

For each flagged item, replace it using the table, or cut it outright. Then read the result out loud. If it doesn't sound like something you'd actually say to a person across a table, cut further.

### The 43-entry replacement table

| Banned | Use instead |
|---|---|
| unlock | open up, start |
| unleash | use, put to work |
| elevate | improve, raise |
| supercharge | speed up, boost |
| leverage (verb) | use |
| harness (verb) | use, tap |
| seamless | smooth, no extra steps |
| robust | solid, reliable |
| cutting-edge | new, latest |
| revolutionary | new, different |
| game-changer | big shift, real difference |
| transformative | changes how X works |
| delve | look at, dig into |
| dive in | start, get into |
| navigate | handle, work through |
| realm | area, space |
| landscape | market, field |
| tapestry | mix, combination |
| journey | process, path |
| empower | let, give the ability to |
| foster | build, encourage |
| streamline | simplify, speed up |
| "in today's fast-paced world" | cut entirely |
| "imagine a world where" | cut, state it directly |
| "the truth is" | cut, just say it |
| "let's face it" | cut |
| "at the end of the day" | cut, or "ultimately" |
| "needless to say" | cut |
| "it's worth noting" | cut |
| arguably | cut, or "I think" |
| "in many ways" | cut |
| can help to | helps, does |
| may potentially | might, could |
| "essentially limitless" | state the real number or limit |
| completely transforms | changes |
| game-changing | useful, valuable |
| "X, not Y" | state the positive directly |
| "not just X, it's Y" | state the positive directly |
| "here's the thing" | cut, go straight to the point |
| "but here's the kicker" | cut |
| "and that's where it gets interesting" | cut |
| "plays a crucial/vital role" | matters because [reason], or name the specific thing it does |
| "a testament to" | shows, proves |
| "more than ever" | cut |

## Quality checklist before finalizing

- No banned words or phrases remain
- No "X, not Y" constructions anywhere
- No three-item rhythm padding
- Sentence lengths vary — not uniformly short, not uniformly long
- At least one concrete number, name, or detail per paragraph
- Reads fine out loud at normal speaking speed
- Every claim is literally true — no overstatement to sound impressive
