# UGC Content Creator

UGC works because it doesn't sound like marketing. The goal isn't better copy — it's the absence of copy-voice entirely.

## The register shift (vs. polished copy)

UGC is a different register than carousel copy or ad copy, not just a casual version of it:

| Polished copy | UGC register |
|---|---|
| "This tool completely changed my workflow." | "Okay so I genuinely didn't expect to use this every day, but I do." |
| "Here are 3 reasons to try X." | "I almost didn't try this because [specific doubt], but..." |
| Clean, complete sentences | Trailing thoughts, self-corrections, "like", "honestly", "okay so" |
| No filler | Light filler is the point — it signals unscripted |
| States the benefit | States the moment the benefit became obvious, in first person |

## Native, non-promotional voice rules

- First person, present-tense reaction, not third-person feature description.
- Include one specific, small, slightly unflattering detail (a doubt, a mistake, a "I almost didn't" moment) — this is what makes it read as real, not as an ad.
- Never use brand-voice words: "amazing", "game-changer", "must-have", "revolutionary", "elevate". If the product is good, describe the specific moment it helped, not an adjective.
- Specificity over polish: "saved me like 2 hours on Tuesday" beats "saves time."
- Talk to one person, not an audience — no "you guys" addressing a crowd, no "for everyone watching."

## Talking-to-camera script structure

1. **Cold open reaction** (0:00–0:03): start mid-thought, as if the camera caught the middle of a real reaction — not a greeting, not a setup.
2. **The specific moment** (0:03–0:15): one concrete scene where the product/thing mattered. Name the day, the task, the doubt.
3. **The honest aside** (0:15–0:20): one small negative, hesitation, or caveat. This is what separates UGC from an ad.
4. **The takeaway** (0:20–0:25): what you'd tell a friend, in one plain sentence.
5. **Soft CTA** (0:25–0:30): casual, not a hard sell — "link's in my bio if you want to try it" register, not "click now."

## Quality checklist

- Does NOT use any word from the brand-voice banned list above
- Contains at least one specific, small, unpolished detail
- Reads like a voice memo to a friend, not a script
- No third-person feature-listing anywhere
- CTA is casual, placed last, and low-pressure
