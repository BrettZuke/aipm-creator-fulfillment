# Viral Reel Generator

## Output format: strict visual-to-audio sync

Write every script as a two-column, timestamped breakdown — never as a paragraph of prose:

```
[0:00–0:02] VISUAL: <exact shot/action on screen>
            AUDIO:  <exact line spoken>

[0:02–0:05] VISUAL: <next shot>
            AUDIO:  <next line>
```

Rules:
- Timestamp every cut. If the visual changes, audio changes lines or a new beat starts — they move together.
- No audio line should run longer than the visual beat it's tied to. If a line needs more time, split the visual into two shots.
- Hook (first line, 0:00–0:02) must work with sound off — the visual alone has to stop a scroll.

## Anti-slop writing rules

These are the generic patterns that make a script sound AI-written or template-written. Cut them on sight:

- No "in this video, I'm going to show you..." — start on the actual content.
- No generic B-roll description ("person typing on laptop", "city skyline at sunset") — every visual must be specific to this script, not a stock placeholder.
- No "let's get into it" / "without further ado" — these are dead air, cut straight to the hook.
- No summarizing what you just said ("so as you can see...") — say it once, move on.
- No "in conclusion" / "to wrap up" — end on the last point or the CTA, not a recap.
- No stacked adjectives for hype ("this incredible, game-changing, must-have tool") — name what it actually does instead.
- Avoid uniform sentence length — spoken delivery needs short punches mixed with one longer explanatory line, not a metronome.

## Built for TikTok / Reels / Shorts

- **Hook window:** first 1.5 seconds decide whether someone keeps watching. The hook line and the hook visual must both land in that window — don't spend it on a logo or intro.
- **Pacing:** cut or change visual every 2–4 seconds. If a single shot runs longer, there needs to be a reason (a demo, a reaction, a held beat for comedic timing).
- **Captions:** assume captions are burned in. Write audio lines short enough to read in one glance — if a caption would wrap to 3 lines, split it.
- **CTA timing:** the ask (follow, comment, link) goes in the final 2–3 seconds, after the payoff has already landed — never before.
- **Length discipline:** match the script length to the idea. A one-point video should be 15–30 seconds. Don't pad to hit a round number.

## Quality checklist

- Hook works with sound off
- Every visual beat has a matching, specific audio line (no orphaned visuals or audio)
- No anti-slop violations from the list above
- Pacing changes visual every 2–4 seconds
- CTA sits in the final beats, not the middle
- Read the audio column alone, out loud — it should sound like talking, not narrating
